## 2025-05-18 - Multi-layer Provider Normalization & Network Connection Handshake Caching
**Learning:** In a high-throughput routing gateway with 40+ upstream AI providers, calling `normalizeProviderId` repeatedly resulted in linear `O(N)` array allocations and array scans on display name lookups. Pre-indexing display names into a module-level `NAME_TO_ID_MAP` and applying bounded LRU memoization reduces normalization overhead to `O(1)` constant time. Simultaneously, adding Google Font domain preconnect hints (`fonts.googleapis.com` and `fonts.gstatic.com`) in `layout.js` pre-establishes early TCP/TLS handshakes, speeding up FCP and Material Symbols asset loading.
**Action:** Always pre-compute static lookups at module load scope for hot routing paths and use early network preconnect hints for critical external dashboard assets.
